# Tarkov Helper — инструкции для LLM

Десктоп-помощник для Escape from Tarkov: карта ценного лута Лаборатории (зоны за картами доступа, двери, выходы), цены PvE/PvP, в разработке — сканер цен в рейде. Rust + GPUI, macOS и Windows. Репозиторий: `bobisdacool1/TarkovHelper`.

## Общение и стиль

- Пользователь пишет по-русски — отвечай по-русски. Интерфейс, комментарии в коде и коммиты — тоже по-русски.
- В интерфейсе предметы называются **короткими именами** (`LEDX`, `GPU`, `0.2BTC`, `Черная`), полное имя — второй строкой/в подсказке.
- Стиль UI — как mapgenie: тёмная панель, золотые акценты, категории с иконками и счётчиками. Палитра — константы `BG/PANEL/CARD/GOLD/GOLD_DIM/TEXT/MUTED` в `src/app.rs`.
- Не коммить и не пушь без явной просьбы. Почта автора в этом репо — `sinitsin.aleksey2003@yandex.ru` (задана в локальном git config, глобальную не трогать: там рабочая почта).

## Команды

```bash
cargo run                      # dev-сборка (зависимости оптимизированы, см. Cargo.toml)
cargo test                     # юнит-тесты (hotkey и др.)
cargo build --release          # ~10 мин из-за LTO, без нужды не запускать
cargo packager --release --formats app,dmg   # упаковка macOS (после cargo build --release)
python3 tools/zone-editor/server.py          # редактор зон: http://localhost:8790 (8765 занят другим сервером)
```

Перед долгими сборками проверь место на диске (`df -h /System/Volumes/Data`): диск у пользователя часто почти полон (Docker, swap), `target/` весит ~8 ГБ.

## Устройство

| `src/main.rs` | запуск, ассеты (SVG-иконки вшиты), глобальные клавиши |

| `src/tiles.rs` | склейка тайлов подложки в картинку на этаж, «запекание» комнат без подложки |
| `src/categories.rs` | подкатегории предметов по `itemCategories` |
| `src/maps.rs` | список карт (доступна только Лаборатория) |

Данные и кэш: `dirs::data_dir()/tarkov-helper/` (на macOS `~/Library/Application Support/tarkov-helper/`): `pve/`, `regular/` (дампы), `maps/` (склеенные этажи), `settings.json`.

## Данные tarkov.dev

- Источник — статические дампы `https://json.tarkov.dev/{pve|regular}/{items,items_ru,items_en,maps,maps_ru,tasks,tasks_ru,hideout,hideout_ru,traders,barters,crafts}`. Формат `{data: ...}`; переводы — словарь `"<id> Name"`, `"<id> ShortName"`, `"hideout_area_N_name"`, `"<taskId> name"`.
- Сезонного режима и арены там нет (404). GraphQL `api.tarkov.dev` бывает недоступен — не полагайся на него.
- Заголовок `User-Agent` обязателен; агент вида `Mozilla/5.0`/python-urllib получает 403. Используем `tarkov-helper/0.1`.
- Цена предмета = максимум из `lastLowPrice` (барахолка; 0 для `noFlea`) и лучшего `sellToTrader.priceRUB`. Комиссию барахолки пользователь видеть не хочет.
- Лут: в дампе есть только **открытый** лут (`lootLoose`) с координатами. Содержимое контейнеров не публикуется — предметы из ящиков (например, смазки) на карте не найти, есть только позиции контейнеров.
- `Need`: требования уровней убежища и задачи `giveItem`; цели с >3 вариантами предметов пропускаем.
- Лестниц в данных нет — размечать вручную.

## Карта Лабы

- Подложка — тайлы `https://assets.tarkov.dev/maps/labs_v4/{technical|1st|2nd}/{z}/{x}/{y}.png`, 256 px, сетка 2^z. Склеиваем зум 4.
- Проекция (tarkov.dev `transform [0.575, 281.2, 0.575, 193.7]`, поворот 270°, тайл 175): `u = (0.575*z + 281.2)/175`, `v = (0.575*x + 193.7)/175` (нормированные 0..1). См. `labs::grid_uv`, `TileRange::project/unproject`.
- Этажи по высоте `y`: `< -0.9` — технический, `>= 3` и в границах `x∈[-271,-101], z∈[-422,-270]` — второй, иначе первый.
- Слой второго этажа — прозрачная накладка; комнату «Чёрная (2 эт.)» tarkov.dev не отрисовал — она `solid: true` и дорисовывается в картинку (`tiles::floor_image`).
- Зоны (`assets/labs_rooms.json`): `{name, key, floor, poly: [[x,z],...], approx?, solid?, texture_from?}`. Углы — 90° (рёбра с отклонением до 12° выравниваются). Редактор сохраняет файл целиком — если правишь файл сам, предупреди пользователя обновить вкладку редактора, иначе он затрёт правки (в редакторе есть проверка, но лучше не доводить).
- В debug зоны читаются из исходников, в релизе — из репозитория (`raw.githubusercontent.com/.../main/assets/labs_rooms.json`) с кэшем, иначе вшитая копия.

## GPUI (0.2.2) — подводные камни

- Нет полного Xcode → фича `runtime_shaders` обязательна.
- Без `[profile.dev.package."*"] opt-level = 3` всё тормозит.
- Встроенный `.tooltip()` имеет зашитую задержку 500 мс — на карте используем свой hover (`hover_listener` + `Hover`).
- Своё поле ввода на сырых key-событиях — плохая идея (ломаются ⌘A/⌘X/IME): используй `text_input::TextInput`.
- Сочетания: `secondary-` = ⌘ на macOS / Ctrl на Windows. Биндинги GPUI срабатывают раньше `on_key_down`.
- Иконка окна на Windows грузится из ресурса exe с id 1 → `build.rs` + `assets/windows/app.rc`. macOS-иконки — набор `assets/app-icon/*.png` (один 1024 px не подходит упаковщику).
- Нет pinch-жеста: зум — любая прокрутка, перемещение — перетаскивание.

## Проверка UI

- `screencapture` для окна приложения не работает (нет прав на запись экрана у шелла).
- Рабочий способ: завернуть `target/debug/tarkov-helper` в `.app` с bundle id `io.github.bobisdacool1.tarkovhelper.dev` (в scratchpad) и смотреть через computer-use (`app_screenshot`, `app_click`). Фоном можно слать только навигационные клавиши, Esc и ⌘A.
- После проверки возвращай настройки пользователя, которые менял, и отпускай приложение (`app_release`).

## Релизы и обновления

- Выпуск: поднять `version` в `Cargo.toml`, тег `vX.Y.Z`, `git push --tags` → `.github/workflows/release.yml` собирает macOS arm64/x86_64 и Windows, подписывает пакеты обновления и выкладывает релиз с `latest.json`.
- Секреты — **Repository secrets** (не Environment): `CARGO_PACKAGER_SIGN_PRIVATE_KEY`, `CARGO_PACKAGER_SIGN_PRIVATE_KEY_PASSWORD`. Ключ и пароль лежат у пользователя в `~/.tarkov-helper-signing/` — никогда не коммить и не выводить их содержимое. Публичный ключ — `assets/updater.pub`. В workflow есть шаг диагностики, он пишет длины/хэши секретов в аннотации (их можно читать через API без логина; логи — только залогиненным).
- `.github/workflows/ci.yml` на каждый пуш собирает macOS и Windows и проверяет иконку в exe.
- Сборки не подписаны Apple/Microsoft — README объясняет обход Gatekeeper/SmartScreen.

## Сканер цен (в разработке)

- Только Windows (игра только там) и только снимок экрана: никакого чтения памяти/инъекций — BattlEye.
- План как у Tarkov Price Viewer: снимок окна → тултип по цвету рамки → OCR названия → нечёткое сопоставление с именами из дампа (ру/англ) → оверлей. TPV под GPL-3 — брать идеи, не код.
- Настройки уже есть (`ScannerSettings`, страница «Сканер» с превью). В оверлее первой строкой — цена за клетку.
