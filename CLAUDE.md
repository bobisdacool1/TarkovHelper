# Tarkov Helper — инструкции для LLM

Десктоп-помощник для Escape from Tarkov: карта ценного лута Лаборатории (зоны за картами доступа, двери, выходы), цены PvE/PvP, журнал рейдов со средним профитом по картам, в разработке — сканер цен в рейде. Rust + GPUI, macOS и Windows. Репозиторий: `bobisdacool1/TarkovHelper`.

Разработка начиналась на macOS, **дальше продолжается на Windows** — там же игра, поэтому там пишется и проверяется сканер.

## Общение и стиль

- Пользователь пишет по-русски — отвечай по-русски. Интерфейс, комментарии в коде и коммиты — тоже по-русски.
- В интерфейсе предметы называются **короткими именами** (`LEDX`, `GPU`, `0.2BTC`, `Черная`), полное имя — второй строкой/в подсказке.
- Стиль UI — как mapgenie: тёмная панель, золотые акценты, категории с иконками и счётчиками. Палитра — `pub(crate)` константы `BG/PANEL/CARD/GOLD/GOLD_DIM/TEXT/MUTED` и виджеты `checkbox/segmented/link/tier_color/with_alpha` в `src/app.rs`.
- Не коммить и не пушь без явной просьбы. Почта автора в этом репо — `sinitsin.aleksey2003@yandex.ru`, имя `bobisdacool1`: на новой машине задай их в **локальном** git config репозитория (`git config user.email ...`), глобальный не трогай.
- Пользователь любит, когда показываешь результат сам (скрин, проверка в запущенном приложении), а не «вроде работает».

## Команды

```bash
cargo run                      # dev-сборка (зависимости оптимизированы, см. Cargo.toml)
cargo test                     # юнит-тесты (hotkey, raids, сканер; на Windows — и реальный OCR ярлыков)
cargo build --release          # долго (LTO), без нужды не запускать
python3 tools/zone-editor/server.py          # редактор зон: http://localhost:8790
```

macOS-упаковка локально: `cargo packager --release --formats app,dmg` (после `cargo build --release`). Релизы собирает CI — локально упаковывать не нужно.

### Windows

- Нужен Rust stable с тулчейном **MSVC** (Visual Studio Build Tools, «Desktop development with C++»). GPUI на Windows рисует через DirectX; фича `runtime_shaders` в Cargo.toml безвредна.
- `build.rs` вшивает иконку в exe через `embed-resource` (`assets/windows/app.rc`, ресурс id 1 — его грузит GPUI для окна/панели задач).
- Данные приложения: `%APPDATA%\tarkov-helper\` (`dirs::data_dir()`).
- Пути и сочетания уже кроссплатформенные (`secondary-` = Ctrl на Windows), шрифт на Windows — `Segoe UI`.

## Данные tarkov.dev

- Источник — статические дампы `https://json.tarkov.dev/{pve|regular}/{items,items_ru,items_en,maps,maps_ru,tasks,tasks_ru,hideout,hideout_ru,traders,barters,crafts}`. Формат `{data: ...}`; переводы — словарь `"<id> Name"`, `"<id> ShortName"`, `"hideout_area_N_name"`, `"<taskId> name"`.
- Сезонного режима и арены там нет (404). GraphQL `api.tarkov.dev` бывает недоступен — не полагайся на него.
- Заголовок `User-Agent` обязателен; агент вида `Mozilla/5.0`/python-urllib получает 403. Используем `tarkov-helper/0.1`.
- Цена предмета = максимум из `lastLowPrice` (барахолка; 0 для `noFlea`) и лучшего `sellToTrader.priceRUB`. **Комиссию барахолки пользователь видеть не хочет** («чистыми» убрано). Цена за клетку = цена / (w×h).
- Лут: в дампе есть только **открытый** лут (`lootLoose`) с координатами. Содержимое контейнеров не публикуется — есть только позиции контейнеров.
- `Need`: требования уровней убежища и задачи `giveItem`; цели с >3 вариантами предметов пропускаем.
- Лестниц в данных нет — размечать вручную.

## Карта Лабы

- Подложка — тайлы `https://assets.tarkov.dev/maps/labs_v4/{technical|1st|2nd}/{z}/{x}/{y}.png`, 256 px, сетка 2^z. Склеиваем зум 4.
- Проекция (tarkov.dev `transform [0.575, 281.2, 0.575, 193.7]`, поворот 270°, тайл 175): `u = (0.575*z + 281.2)/175`, `v = (0.575*x + 193.7)/175`. См. `labs::grid_uv`, `TileRange::project/unproject`.
- Этажи по высоте `y`: `< -0.9` — технический, `>= 3` и в границах `x∈[-271,-101], z∈[-422,-270]` — второй, иначе первый.
- Переключение этажей **сохраняет зум и точку под центром** (`set_floor_view`); «вписать» — только при первом показе и по кнопке ⤢.
- Комнату «Чёрная (2 эт.)» tarkov.dev не отрисовал — `solid: true`, дорисовывается в картинку этажа.
- Зоны (`assets/labs_rooms.json`): `{name, key, floor, poly: [[x,z],...], approx?, solid?, texture_from?}`. Углы — 90°. Редактор сохраняет файл целиком — если правишь файл сам, попроси пользователя обновить вкладку редактора.
- В debug зоны читаются из исходников, в релизе — из репозитория (`raw.githubusercontent.com/.../main/assets/labs_rooms.json`) с кэшем, иначе вшитая копия.

## GPUI (0.2.2) — подводные камни

- macOS без полного Xcode → фича `runtime_shaders`.
- Без `[profile.dev.package."*"] opt-level = 3` всё тормозит.
- Встроенный `.tooltip()` — задержка 500 мс; на карте свой hover (`hover_listener` + `Hover`).
- Поле ввода — только `text_input::TextInput` (сырые key-события ломают ⌘A/⌘X/IME).
- Биндинги GPUI срабатывают раньше `on_key_down`. Во время записи хоткея страница сканера перехватывает клики в фазе захвата (`capture_any_mouse_down`), чтобы не нажимались её кнопки.
- Кнопки мыши: `MouseButton::Navigate(Back/Forward)` = Mouse 4/5 (mac `buttonNumber` 3/4, Windows `XBUTTON1/2`).
- Окна `WindowKind::PopUp`:
  - **macOS**: это NSPanel — по умолчанию прячется при деактивации приложения и сохраняет спрятанный заголовок/системный контур. Лечится в `raid_overlay::keep_visible` через objc: `setHidesOnDeactivate:NO`, прозрачный заголовок без разделителя, `setHasShadow:NO`; окно прозрачное, панель со скруглением/рамкой/тенью рисуем сами с полями `OVERLAY_MARGIN`.
  - **Windows**: GPUI делает PopUp с `WS_EX_TOOLWINDOW`, но **не TOPMOST** — для оверлея поверх игры нужно самим вызвать `SetWindowPos(HWND_TOPMOST)` по raw handle (сейчас в `keep_visible` для Windows заглушка).
- Нет pinch-жеста: зум — любая прокрутка, перемещение — перетаскивание.

## Проверка UI

- На Windows — просто `cargo run` и смотреть/кликать самому или просить скрин у пользователя.
- На macOS `screencapture` окна не работает; рабочий способ — завернуть `target/debug/tarkov-helper` в `.app` с bundle id `io.github.bobisdacool1.tarkovhelper.dev` и смотреть через computer-use (`app_screenshot`/`app_click`; фоном — только навигационные клавиши, Esc, ⌘A, без правого клика).
- После проверки возвращай настройки пользователя, которые менял, не добавляй тестовые рейды в его журнал.

## Релизы и обновления

- Выпуск: поднять `version` в `Cargo.toml`, коммит, тег `vX.Y.Z`, `git push origin main vX.Y.Z` → `.github/workflows/release.yml` собирает macOS arm64/x86_64 и Windows, подписывает пакеты обновления, выкладывает релиз с `latest.json`. Вышли: v0.1.0, v0.2.0, v0.3.0.
- Секреты — **Repository secrets**: `CARGO_PACKAGER_SIGN_PRIVATE_KEY`, `CARGO_PACKAGER_SIGN_PRIVATE_KEY_PASSWORD`. Ключ и пароль лежат у пользователя на маке в `~/.tarkov-helper-signing/` — никогда не коммить и не выводить. Публичный ключ — `assets/updater.pub`. Шаг диагностики в workflow пишет длины/хэши секретов в аннотации (читаются через API без логина; логи — только залогиненным).
- `.github/workflows/ci.yml` на каждый пуш собирает macOS и Windows и проверяет иконку в exe — **это единственная проверка Windows-сборки, если пишешь на маке**.
- Обновлятор в 0.1.0/0.2.0 проверяет только при запуске — открытое приложение о новой версии не узнает. В 0.2.0+ есть «Настройки → Проверить обновления».
- Сборки не подписаны Apple/Microsoft — README объясняет обход Gatekeeper/SmartScreen.

## Сканер цен (Windows)

Подход — **по ярлыкам ячеек, не по тултипу** (прототип и цифры — `tools/scanner-prototype/README.md`). Только снимок экрана — никакого чтения памяти/инъекций (BattlEye); игра в режиме «оконный без рамки».

Как работает (`src/scanner/`):
1. Хоткеи — низкоуровневые хуки в своём потоке (`win::start_hooks`). Хук мыши ставится, только если в сочетаниях есть кнопка мыши. По умолчанию срабатывают, только когда впереди окно с заголовком `EscapeFromTarkov` (`only_in_game`). Пока на странице записывается сочетание, хуки молчат.
2. Снимок монитора под курсором (GDI `BitBlt`), процесс — Per-Monitor DPI aware (`make_dpi_aware` в `main`).
3. `vision`: клетка ≈ `63 × min(w/1920, h/1080)` ±15 %, фаза сетки — по профилю светлых линий вокруг курсора; занятость — σ яркости > 8; разные предметы — светлая рамка на границе **или** ровный перепад фона (у Wedge и жетона рамки нет). Скан рюкзака — связная область «клеток сетки» от курсора.
4. OCR полоски ярлыка (правые ≤3 клетки, верхние 27 %): белый текст → тёмный на белом (контраст 60–140, ×2 — подобрано тестом `tune_label_preprocessing`), движки en и ru из системы.
5. `matcher` по `short`/`short_en` (кириллица-двойники → латиница, `ø` → `0`), фильтр по размеру, из одинаковых ярлыков — самый дорогой.
6. Один предмет → карточка-окно (PopUp, TOPMOST, `WS_EX_NOACTIVATE`, `WDA_EXCLUDEFROMCAPTURE`) справа от квадрата или в углу; скрывается по таймеру / движению мыши / отпусканию клавиши / клавише скрытия. Весь контейнер (`raid_key`, F8) → `raid_overlay::open` с реальными строками.
- Win32-вызовы окон GPUI — **вне** `update` (в отдельной задаче), иначе оконная процедура GPUI может попасть в занятое состояние приложения.
- «Сохранять снимки сканов» → `%APPDATA%\tarkov-helper\scanner-debug\` (область вокруг курсора с квадратами + txt с текстом OCR) — по ним дотюнивать распознавание на реальных скринах.

Не проверено в игре / не сделано: поведение карточки в реальной игре; другие разрешения, кроме 1440p; стаки (число справа снизу), жетоны; оружие в сборе (размер больше базового — сопоставление только по имени).
