# Прототип распознавания рюкзака

Проверка идеи «сначала квадраты предметов, потом текст в их правом верхнем углу» на настоящем скрине (`backpack.png`, ник на жетоне замазан).

```bash
swiftc -O ocr.swift -o ocr          # macOS: OCR через Vision (на Windows — Windows.Media.Ocr)
python3 boxes.py backpack.png crops ./ocr "<папка дампа PvE>"   # нужен Pillow
```

## Алгоритм

1. **Рамка сетки** — в прототипе задана руками (`X0..X1, Y0..Y1`, 5×6 клеток по ~84 px). В продукте — автопоиск: внешняя рамка сетки контрастная (столбцы/строки, где почти все пиксели серые 60–110).
2. **Занятость клетки** — стандартное отклонение яркости внутри клетки: пустые ≈ 2, занятые ≥ 14 (порог 8).
3. **Склейка в предметы** — на границе соседних занятых клеток ищем светлую рамку (пиксель на границе ярче соседей в 4 px поперёк на >10). Доля таких пикселей вдоль границы: внутри одного предмета 0,03–0,23, между разными предметами 0,83–1,00 → порог 0,5, union-find.
4. **OCR** только полоски ~22 px в верхней части квадрата (ярлык выровнен по правому краю), увеличенной ×3.
5. **Сопоставление** с `ShortName` из дампа (ру/англ), без пунктуации: точное → по началу (игра обрезает длинные имена: `Augmenti`) → ближайшее по похожести. Затем **фильтр по размеру** w×h (или h×w).

## Результат на `backpack.png`

12 квадратов найдено с верными размерами, 11 опознано (Sausage, Roler, 0.2BTC, Wedge, Wires ×3, SAS, SVDS, Salewa, Augmentin), не опознан жетон (на нём ник игрока). SVDS: 6 кандидатов по имени → 3 по размеру. Сумма ≈ 991 000 ₽ по ценам PvE на 20.11.2026.

## Что ещё учесть в продукте

- стаки (деньги, патроны): число справа снизу квадрата;
- жетоны: распознавать отдельно (уровень слева снизу);
- оружие в сборе: ярлык один, модули не считаются;
- закрытые контейнеры: содержимое не видно;
- масштаб интерфейса и разрешение: размер клетки брать из найденной сетки, не константой.
